This page is the **canonical registry** for Wraith Protocol contract deployments. An address only ships here after it is recorded in the SDK deployment manifest and the contracts repo deployment manifest. If you find a contract address anywhere else in the docs, compare it against this page.

The machine-readable copy lives at [`scripts/contract-registry.json`](https://github.com/wraith-protocol/docs/blob/develop/scripts/contract-registry.json). CI cross-verifies every recorded fact against pinned authoritative sources — the `@wraith-protocol/sdk` `getDeployment()` manifest from the lockfile, the live on-chain WASM hash and creation timestamp for each deployed contract, and the contracts-repo deployment manifest at a pinned commit — and fails when any of them disagree or when a stale placeholder is reintroduced.

<Note>
  Public testnet contract state can change at any time, and testnet is reset roughly
  quarterly. Mainnet is not deployed yet. Treat **Not deployed** rows as authoritative
  until a release says otherwise.
</Note>

## Status legend

| Status | Meaning |
|---|---|
| **Live** | Deployed and usable today. Address, version, artifact hash, and ledger are recorded. |
| **Pending** | Deployment is planned but not complete. Do not use a placeholder address. |
| **Not deployed** | No Wraith contracts on this network. |

## Verify a deployed contract

Confirm the artifact hash above matches the WASM installed on-chain before you trust an address:

```bash
# Fetch the deployed WASM for a contract id
stellar contract fetch \
  --id CCJLJ2QRBJAAKIG6ELNQVXLLWMKKWVN5O2FKWUETHZGMPAD4MHK7WVWL \
  --network testnet \
  --out deployed.wasm

# Compare the hash with the registry
sha256sum deployed.wasm
# 7ef72be0b50f6b25ddd935aa0c0abcf18af28754a2e16fb5b40dcf9a4b497fc8
```

## Other chains

EVM, Solana, and CKB deployments are published through the SDK rather than this Stellar-focused page. Read them from the SDK:

```typescript
import { getDeployment as getEvmDeployment } from "@wraith-protocol/sdk/chains/evm";
import { getDeployment as getSolanaDeployment } from "@wraith-protocol/sdk/chains/solana";
import { getDeployment as getCkbDeployment } from "@wraith-protocol/sdk/chains/ckb";

console.log(getEvmDeployment("horizen").contracts);
console.log(getSolanaDeployment("solana").contracts);
console.log(getCkbDeployment("ckb").contracts);
```
