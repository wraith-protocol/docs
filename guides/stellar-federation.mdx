---
title: "Stellar Federation"
description: "Resolve Stellar federation addresses using the Stellar SDK"
---

The Wraith SDK does not currently provide a federation resolver. Use the federation support from `@stellar/stellar-sdk` to resolve a `name*domain` address to its Stellar account record.

```typescript
import { Federation } from "@stellar/stellar-sdk";

const record = await Federation.Server.resolve("alice*example.com");
console.log(record.account_id);
```

The resolver reads the domain's `stellar.toml`, finds its federation server, and queries that server. Handle lookup failures in your application and let the user enter a Stellar account ID directly when resolution is unavailable.

```typescript
import { Federation } from "@stellar/stellar-sdk";

try {
  const record = await Federation.Server.resolve("alice*example.com");
  console.log(record.account_id, record.memo_type, record.memo);
} catch (error) {
  console.error("Federation address could not be resolved", error);
}
```
