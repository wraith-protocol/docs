---
title: "Fetching announcements"
description: "Fetch EVM stealth announcements with the SDK"
---

The published SDK does not expose a streaming API. For EVM chains, use `fetchAnnouncements` to retrieve the announcements currently indexed by the configured subgraph. Call it again when your application needs a refresh.

## Fetch announcements

```typescript
import { fetchAnnouncements } from "@wraith-protocol/sdk/chains/evm";

const announcements = await fetchAnnouncements("ethereum");
for (const announcement of announcements) {
  console.log(announcement);
}
```

Pass a subgraph URL as the second argument when you need to use a specific endpoint:

```typescript
import { fetchAnnouncements } from "@wraith-protocol/sdk/chains/evm";

const announcements = await fetchAnnouncements(
  "base",
  "https://example.com/subgraph",
);
```

The function returns a promise containing the indexed announcements. It does not subscribe to live updates, support cancellation, or provide stream backpressure controls.
